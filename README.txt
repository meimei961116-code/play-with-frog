和奶蛙玩｜手機分享版

使用方式
1. 傳送「和奶蛙玩_手機分享版.zip」給對方。
2. 先完整解壓縮 ZIP；不要直接在 ZIP 預覽畫面開啟 index.html。
3. 解壓縮後，保持 index.html、影片與音效檔在同一個資料夾。
4. 用瀏覽器開啟 index.html，即可點擊角色和按鈕。

手機提示
部分手機瀏覽器會限制從本機檔案（file://）讀取影片或音效。若解壓縮後媒體無法播放，請把整個資料夾放到靜態網站空間，再用網址開啟。

媒體格式
影片為 MP4（H.264/AAC）；音效為 M4A（AAC）。這些素材由原始 MOV 重新封裝／轉換，方便手機瀏覽器播放。

請不要單獨移動或重新命名 index.html 引用的影片與音效檔。
